# Call-in en français

Ce fork ajoute une interface française à [Call-in](https://github.com/mashbean/call-in), un outil open source pour recueillir des questions et des réactions en direct pendant une présentation.

L’instance BordeauxJS est accessible sur [call-in.bordeauxjs.com](https://call-in.bordeauxjs.com/). Les informations de configuration et de mise à jour figurent dans [SELFHOST.md](./SELFHOST.md). Le projet d’origine, sa documentation et ses mentions de licence restent disponibles dans [README.md](./README.md).
